- **작성일:** 2026-09-10
- **상태:** UI/UX Design Baseline

본 문서는 `03_UI_COVERAGE_ANALYSIS.md`가 정의한 5개 디자인 Screen(SCR-001~005)에 실제 화면 구성을 배치한다. Airbnb DESIGN.md는 타이포그래피 절제, 카드 중심 레이아웃, 단일 포인트 컬러 운용 방식만 참고했고, Rausch 색상값·Airbnb Cereal 폰트명·워드마크·"Guest favorite" 같은 상표 요소는 그대로 가져오지 않았다.

### 1-5. 접근성·인터랙션 공통 규칙

- 모든 인터랙티브 요소(버튼, 링크, 탭, Chip, Card CTA)는 키보드 `Tab` 이동과 `:focus-visible` 2px 코랄 아웃라인을 지원한다.
- 터치 대상은 모바일 기준 최소 44×44px을 확보한다(아이콘 버튼도 히트 영역을 44px로 확장).
- 색상만으로 상태를 구분하지 않고 텍스트 라벨·아이콘을 병기한다.
- 이미지에는 실제 장소를 설명하는 대체텍스트를 사용한다(예: `alt="태국 방콕 왓아룬 사원 전경"`), `이미지`, `사진1` 같은 무의미한 alt는 사용하지 않는다.

## 2. 콘텐츠 밀도·섹션 배치 공통 규칙

- 모든 화면은 Header–Section 1–Section N–Footer 순서로 배치하고 목적 없는 Section을 두지 않는다.
- Desktop 콘텐츠 폭은 1200~1280px로 중앙 정렬하고 Section 상하 여백은 64~96px, Mobile은 40~64px로 좁힌다.
- Hero는 뷰포트 전체 높이를 차지하지 않는다. 1440px 기준 Hero 아래 다음 Section의 제목 일부가 스크롤 없이 보이도록 Hero 높이를 560~640px로 제한한다.
- 레이아웃 패턴은 Hero, Card Grid, 좌우 분할, Chip 목록, 3단계 안내, CTA Banner 6종을 화면마다 교차 배치해 같은 Card 반복을 피한다.
- 각 Section은 제목 1개, 1~3문장 설명, 실제 콘텐츠 또는 명확한 CTA를 함께 둔다.
- 데이터가 없는 Section은 "준비 중"류 문구 대신 상황 설명 + 이용 방법 + 다음 행동 CTA로 구성한 Empty State를 사용한다.

**Drawer/Modal 규칙:** Section 2·3의 여행지 카드와 Section 5의 국가 카드는 같은 화면 위에 Drawer(Desktop 우측 480px 슬라이드, Mobile 하단 전체화면 Sheet)를 열며 페이지 이동을 하지 않는다. 여행지 상세 Drawer 내부에 "국가 안전정보 보기" 링크를 두면 같은 Drawer 스택에서 안전정보 화면으로 전환된다(REQ-FUNC-006).

**CTA 배치 원칙:** Hero → `/travel-tools`, Section 6 → `/mates`, Section 7 → `/about`로 각 Section 문맥에 맞는 CTA 하나씩만 강조한다.
